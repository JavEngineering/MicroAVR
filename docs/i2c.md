# I2C/TWI Peripheral Documentation

## 1. What the Peripheral Does

The TWI (Two-Wire Interface) on the ATmega328P implements the I2C protocol - a synchronous, multi-master, multi-slave serial communication bus using only two wires.

**Key Features:**
- **Master/Slave** operation (Master is primary use case)
- **Standard mode**: 100 kHz
- **Fast mode**: 400 kHz
- **7-bit addressing** (127 devices)
- **Multi-master** arbitration support
- **Pull-up resistors** required on SDA/SCL (typically 4.7kΩ)

**Common Uses:**
- Sensors (accelerometers, gyros, temperature, pressure)
- EEPROM/Flash memory
- RTC (real-time clocks)
- I/O expanders

## 2. Physical/Electrical Intuition

```
                    ┌─────────────────────┐
                    │      ATmega328P     │
                    │      (Master)       │
                    │                     │
         SDA ──────┤ PC4 (A4)            │
                    │                     │
         SCL ──────┤ PC5 (A5)            │
                    │                     │
         Device ◄──┤ 4.7kΩ pull-up       │
         Device ◄──┤ 4.7kΩ pull-up       │
                    └─────────────────────┘
```

**Signal Lines:**
- **SDA** (Serial Data) - Bidirectional data line
- **SCL** (Serial Clock) - Clock generated by master

**Protocol:**
- **Start**: SDA falls while SCL HIGH
- **Address**: 7-bit + R/W bit
- **Ack/Nack**: Receiver pulls SDA LOW (ACK) or HIGH (NACK)
- **Stop**: SDA rises while SCL HIGH

**Bus Speeds:**
| Mode | Frequency | TWBR @ 16MHz (PS=1) |
|------|-----------|---------------------|
| Standard | 100 kHz | 72 |
| Fast | 400 kHz | 12 |

## 3. MicroAVR API

### Concise API (Primary)
```c
// Initialization
I2C_begin();              // 100kHz default
I2C_begin_fast();         // 400kHz
I2C_begin(100, I2C_PS_1); // Custom

// Low-level operations
I2C_start();              // Generate START
I2C_rep_start();          // Repeated START
I2C_stop();               // Generate STOP
uint8_t status = I2C_write(0x55);  // Write byte, return status
uint8_t data = I2C_read_ack();     // Read with ACK
uint8_t data = I2C_read_nack();    // Read with NACK (last byte)
uint8_t status = I2C_status();     // Get TWSR & 0xF8

// Device-level operations (complete transactions)
bool ok = I2C_device_write(0x68, buf, len);           // Write to device
bool ok = I2C_device_read(0x68, 0x3B, buf, len);     // Read from device

// Cleanup
I2C_end();
```

### Fluent API (Optional)
```c
i2c_device_write(0x68, data, len);
i2c_device_read(0x68, 0x3B, buf, 2);
```

### Prescaler Constants
```c
#define I2C_PS_1    0x00  // TWPS = 00
#define I2C_PS_4    0x01  // TWPS = 01
#define I2C_PS_16   0x02  // TWPS = 10
#define I2C_PS_64   0x03  // TWPS = 11
```

### Status Codes (TWSR & 0xF8)
```c
#define I2C_START          0x08
#define I2C_REP_START      0x10
#define I2C_MT_SLA_ACK     0x18  // Master TX SLA+W, ACK received
#define I2C_MT_SLA_NACK    0x20  // Master TX SLA+W, NACK received
#define I2C_MT_DATA_ACK    0x28  // Master TX data, ACK received
#define I2C_MR_SLA_ACK     0x40  // Master RX SLA+R, ACK received
#define I2C_MR_DATA_ACK    0x50  // Master RX data, ACK sent
#define I2C_MR_DATA_NACK   0x58  // Master RX data, NACK sent
```

## 4. Simple Example

### Read from I2C Device (e.g., MPU6050 at 0x68)
```c
#include <microavr/microavr.h>

int main(void) {
    I2C_begin();  // 100kHz

    uint8_t data[2];

    while (1) {
        if (I2C_device_read(0x68, 0x3B, data, 2)) {
            // Successfully read 2 bytes from register 0x3B
            GPIO_toggle(PB5);  // Blink LED on success
        }
        delay_ms(100);
    }
}
```

### Write to I2C Device
```c
uint8_t config[] = { 0x6B, 0x00 };  // Register 0x6B = 0 (wake up MPU6050)
I2C_device_write(0x68, config, 2);
```

## 5. What the AVR Is Actually Doing

### Initialization (100kHz)
```
I2C_begin();
         │
         ▼
TWSR = 0;          // Prescaler = 1
TWBR = 72;         // 16MHz / (16 + 2*72*1) = 100kHz
TWCR = (1<<TWEN);  // Enable TWI
```

### Device Write Transaction
```
I2C_device_write(0x68, buf, 2);
         │
         ▼
I2C_start();
         │
         ▼
TWCR = TWINT|TWSTA|TWEN; wait TWINT
TWSR = 0x08 (START transmitted)
         │
         ▼
I2C_write((0x68<<1)|0);  // SLA+W
         │
         ▼
TWDR = 0xD0; TWCR=TWINT|TWEN; wait
TWSR = 0x18 (SLA+W transmitted, ACK)
         │
         ▼
I2C_write(reg);          // Register address
TWSR = 0x28 (Data transmitted, ACK)
         │
         ▼
I2C_write(data[0]);
I2C_write(data[1]);
         │
         ▼
I2C_stop();
         │
         ▼
TWCR = TWINT|TWSTO|TWEN
```

### Device Read Transaction
```
I2C_device_read(0x68, 0x3B, data, 2);
         │
         ▼
I2C_start() → SLA+W (0xD0) → reg (0x3B)
         │
         ▼
I2C_rep_start() → SLA+R (0xD1)
         │
         ▼
I2C_read_ack()  → data[0] (with ACK)
I2C_read_nack() → data[1] (with NACK, last byte)
         │
         ▼
I2C_stop()
```

## 6. Register-Level Equivalent

| MicroAVR API | AVR Register Operation |
|--------------|------------------------|
| `I2C_begin()` | `TWSR=0; TWBR=72; TWCR=(1<<TWEN);` |
| `I2C_begin_fast()` | `TWSR=0; TWBR=12; TWCR=(1<<TWEN);` |
| `I2C_start()` | `TWCR=(1<<TWINT)|(1<<TWSTA)|(1<<TWEN); wait;` |
| `I2C_rep_start()` | Same as start |
| `I2C_stop()` | `TWCR=(1<<TWINT)|(1<<TWSTO)|(1<<TWEN);` |
| `I2C_write(d)` | `TWDR=d; TWCR=(1<<TWINT)|(1<<TWEN); wait;` |
| `I2C_read_ack()` | `TWCR=(1<<TWINT)|(1<<TWEA)|(1<<TWEN); wait;` |
| `I2C_read_nack()` | `TWCR=(1<<TWINT)|(1<<TWEN); wait;` |
| `I2C_status()` | `return TWSR & 0xF8;` |

**Manual Bare-Metal Equivalent:**
```c
TWSR = 0;
TWBR = 72;  // 100kHz @ 16MHz
TWCR = (1<<TWEN);

// Write to device
TWCR = (1<<TWINT)|(1<<TWSTA)|(1<<TWEN);
while(!(TWCR&(1<<TWINT)));
TWDR = (0x68<<1)|0;
TWCR = (1<<TWINT)|(1<<TWEN);
while(!(TWCR&(1<<TWINT)));
TWDR = 0x3B;
TWCR = (1<<TWINT)|(1<<TWEN);
while(!(TWCR&(1<<TWINT)));

// Repeated start for read
TWCR = (1<<TWINT)|(1<<TWSTA)|(1<<TWEN);
while(!(TWCR&(1<<TWINT)));
TWDR = (0x68<<1)|1;
TWCR = (1<<TWINT)|(1<<TWEN);
while(!(TWCR&(1<<TWINT)));

// Read bytes
TWCR = (1<<TWINT)|(1<<TWEA)|(1<<TWEN);  // ACK
while(!(TWCR&(1<<TWINT)));
data[0] = TWDR;

TWCR = (1<<TWINT)|(1<<TWEN);  // NACK last
while(!(TWCR&(1<<TWINT)));
data[1] = TWDR;

TWCR = (1<<TWINT)|(1<<TWSTO)|(1<<TWEN);
```

## 7. Relevant ATmega328P Registers

| Register | Address | Description |
|----------|---------|-------------|
| `TWBR` | 0xB8 | TWI Bit Rate Register |
| `TWSR` | 0xB9 | TWI Status Register |
| `TWDR` | 0xBB | TWI Data Register |
| `TWCR` | 0xBC | TWI Control Register |
| `TWAR` | 0xBA | TWI (Slave) Address Register |
| `TWAMR` | 0xBD | TWI Address Mask Register |

**TWCR Bits:**
| Bit | Name | Description |
|-----|------|-------------|
| 7 | TWINT | TWI Interrupt Flag |
| 6 | TWEA | TWI Enable Acknowledge |
| 5 | TWSTA | TWI START Condition |
| 4 | TWSTO | TWI STOP Condition |
| 3 | TWWC | TWI Write Collision Flag |
| 2 | TWEN | TWI Enable |
| 1 | — | Reserved |
| 0 | TWIE | TWI Interrupt Enable |

## 8. Performance / Code Size Notes

### Flash Usage (ATmega328P @ 16MHz, -Os)
| Implementation | Flash (bytes) | SRAM (bytes) |
|----------------|---------------|--------------|
| MicroAVR (this lib) | ~156 | 0 |
| Bare AVR C | ~150 | 0 |
| Arduino `Wire` | ~2000+ | ~100+ |

### Timing (100kHz Standard Mode)
| Operation | Time |
|-----------|------|
| START + SLA+W + ACK | ~30 μs |
| Data byte + ACK | ~10 μs |
| Repeated START | ~10 μs |
| Data byte + ACK/NACK | ~10 μs |
| STOP | ~5 μs |
| **Total (write 2 bytes)** | ~65 μs |
| **Total (read 2 bytes)** | ~75 μs |

### Assembly (I2C_device_write)
```asm
; I2C_start()
ldi r24, 0xA4
sts TWCR, r24
wait_start:
lds r24, TWCR
sbrs r24, TWINT
rjmp wait_start

; SLA+W
ldi r24, 0xD0
sts TWDR, r24
ldi r24, 0x84
sts TWCR, r24
wait_sla:
lds r24, TWCR
sbrs r24, TWINT
rjmp wait_sla
```

## 9. Common Mistakes

| Mistake | Problem | Fix |
|---------|---------|-----|
| Missing pull-up resistors | No communication | Add 4.7kΩ pull-ups on SDA/SCL |
| Wrong address format | Device not responding | Use 7-bit address (0x68), library shifts <<1 |
| Missing repeated start | Read fails | Use `I2C_device_read()` which handles rep_start |
| Wrong ACK/NACK on read | Device keeps sending | NACK on last byte (`read_nack`) |
| No pull-ups on custom PCB | Unstable | Always add 4.7kΩ to VCC |
| Bus contention | Multiple masters | Use multi-master arbitration (built-in) |

## 10. Bare-Metal Progression

### Step 1: MicroAVR API (Learning)
```c
I2C_begin();
I2C_device_read(0x68, 0x3B, data, 2);
```

### Step 2: Understand the Mapping
```
0x68 (7-bit) → SLA+W = 0xD0, SLA+R = 0xD1
Register 0x3B → written after SLA+W
Repeated start → SLA+R → read data
```

### Step 3: See Register Equivalent
```c
TWBR = 72; TWCR = (1<<TWEN);
TWCR = (1<<TWINT)|(1<<TWSTA)|(1<<TWEN);
```

### Step 4: Modify Registers Directly
```c
TWBR = 12;  // 400kHz
TWCR |= (1<<TWSTA);  // Manual start
```

### Step 5: Write Bare-Metal AVR C
```c
#include <avr/io.h>
#include <util/delay.h>

int main(void) {
    TWSR = 0; TWBR = 72; TWCR = (1<<TWEN);
    while (1) {
        // ... bare TWI operations
    }
}
```
